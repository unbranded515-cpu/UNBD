# Assets

Drop real brand assets here and reference them from components.

- **`logo.png`** — the Zaika wordmark. Once added, follow the commented
  `import` + `<img>` lines in `../components/ui/Logo.jsx` to swap out the text
  placeholder.
- **Photography** — hero, dish, kitchen and gallery images. Import them and pass
  as the `src` prop to `Placeholder` (or set the `heroImage` const in
  `../components/home/Hero.jsx`). Each swap is a one-line change.

# Images

Drop real photos into this folder using the exact filenames below and they
replace the labelled placeholder boxes automatically — no code changes needed.

## Home page
- `hero.jpg` — full-width hero: showroom sectional styled in a living room (landscape, 1600px+ wide)
- `cat-sofas.jpg` — category tile: sofas & sectionals
- `cat-beds.jpg` — category tile: beds & storage beds
- `cat-mattresses.jpg` — category tile: mattresses
- `cat-dining.jpg` — category tile: dining & tables
- `cat-clearance.jpg` — category tile: clearance
- `cat-custom.jpg` — category tile: custom builds
- `custom-workshop.jpg` — custom section: fabric swatches / workshop
- `ig-1.jpg` … `ig-4.jpg` — Instagram strip thumbnails (square)
- `og-default.jpg` — social share image (1200×630) used when a page is shared

## Custom page
- `custom-swatches.jpg` — fabric swatches or a finished custom sofa

## Showroom page
- `showroom.jpg` — wide shot of the Kingston showroom floor

## Products
One image per product, named to match the `image` field in
`/src/data/products.json` (e.g. `storage-bed-queen.jpg`). Recommended: 1200×900,
JPG or WebP, under ~300 KB each for fast mobile loading.
